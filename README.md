# Voria Website

## Visual identity

- Display / headings: **Sora** (Google Fonts)
- Body / interface: **DM Sans** (Google Fonts)
- Fonts load from Google Fonts with `display=swap`; system sans-serif fallback is provided.

## Brand palette from the supplied Voria logo

| Color | Hex | Intended use |
|---|---|---|
| Indigo | `#374B88` | Primary actions, brand headings, key navigation accents |
| Sky blue | `#51ABDF` | Highlights, focus states, soft visual accents |
| Blue | `#4776BA` | Secondary accents, links and supporting UI elements |
| Bronze | `#A57932` | Small premium details and section labels |
| Muted gold | `#C0AD68` | Limited decorative highlights |

The neutral system uses soft white/blue-gray surfaces and deep navy text so that the logo colors remain accents rather than competing with the logo.

## Responsive layout

The stylesheet includes responsive refinements for wide desktops, laptops, tablets, and phones, with breakpoints at 1440px, 1100px, 900px, 650px, and 380px. Mobile navigation, hero devices, pricing cards, process steps, About, Contact, forms, and footer adapt to narrower widths.

## Run locally

Open `index.html` in a browser. The Google Fonts connection requires internet access; fallback sans-serif fonts are used if Google Fonts cannot load.
